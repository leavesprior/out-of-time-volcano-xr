# Out of Time — Volcano (WebXR)

Entry for the Meta VR Start Developer Competition 2026 (Adapted division, Entertainment track).

**Open this page in the Meta Quest Browser** (Quest 3 / 3S) and press **Enter AR**. Hands-first: pinch the
Guide's pocket watch to step back along the line of time. On a desktop browser the page loads but
Enter AR needs a WebXR headset.

You stand on a real street. The Guide, a fictional red-coated narrator, tells you what stood in the
same place about 1867 in Volcano, California. Every historical line she says is a short sourced fact
(see `CREDITS.md`); anything else is a plain instruction or is marked as simplified.

## Status (honest)

- Built with the Immersive Web SDK (IWSDK) and three.js. Runs in a WebXR emulator (IWER).
- **Not yet tested on a headset** at the time of this release. Frame rate, hand tracking and plane
  detection on a Quest are still to be measured.
- This repository holds the built, static release only. Free to play, no ads, no sign-in.
